# Kit acoustique

Les neuf sons de `public/audio/metronome-kit/` proviennent de [Virtuosity Drums, Versilian Studios](https://versilian-studios.com/virtuosity-drums/), publié sous [CC0 1.0](https://github.com/sfzinstruments/virtuosity_drums/blob/9f04cf9a734527edfbb0a4eee1f674e45bbf71bc/LICENSE).

| WAV | Enregistrement dans le [répertoire Samples](https://github.com/sfzinstruments/virtuosity_drums/tree/9f04cf9a734527edfbb0a4eee1f674e45bbf71bc/Samples) |
| --- | --- |
| kick | `kickmic/kick/kickmic_kick_snon_vl3_rr1.flac` |
| snare | `mid/snare/mid_snare_center_vl15.flac` |
| closed-hat | `mid/hh/mid_hh_closed_vl3_rr1.flac` |
| open-hat | `mid/hh/mid_hh_open_vl3_rr1.flac` |
| tom-high | `mid/htom/mid_htom_center_vl12.flac` |
| tom-mid | `mid/htom/mid_htom_offcenter_vl12.flac` |
| tom-low | `mid/ltom/mid_ltom_center_vl12.flac` |
| crash | `mid/crash/mid_crash_crash_vl3_rr1.flac` |
| ride | `mid/ride/mid_ride_ride_vl3_rr1.flac` |

Le tom médium utilise une frappe décentrée du tom aigu, transposée trois demi-tons plus bas.
Les échantillons ont été convertis en PCM mono 16 bits à 44,1 kHz, recalés sur l’attaque,
normalisés à −1 dBFS et raccourcis avec un fondu de fin. La grosse caisse, la caisse
claire et les deux charlestons sont partagés avec les boucles du métronome.
